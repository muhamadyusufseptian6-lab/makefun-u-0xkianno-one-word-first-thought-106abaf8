One word. The first that comes to mind. No topic, no explanation, no second draft.

This entry's word is **psithurism** — the sound of wind whispering through the trees. On a still afternoon the leaves start talking before anything moves: a sound you hear first, and the word itself sounds like the wind it names. It is the word that arrives before thinking gets a say.

`main.ts` (Node 22, standard library only, deterministic) writes that single word to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
